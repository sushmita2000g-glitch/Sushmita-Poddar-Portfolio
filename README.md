# Sushmita Poddar — Portfolio

This is my personal portfolio site. Built it to have one place that shows what I actually work on, instead of just a resume PDF sitting in someone's downloads folder.

**Live here:** https://sushmita-poddar-portfolio-sushmita-s-projects1.vercel.app

## What's on it

- A quick intro — who I am and what I do
- My skills, grouped by what they're actually for (not just a random tag cloud)
- 5 data science projects, each with a link to the live app or the repo
- Education + certifications
- Contact info (email, phone, LinkedIn, GitHub)

## Projects featured

1. **Demand Forecasting using ARIMA** — forecasting model on 900K+ sales records
2. **Customer Segmentation & Churn Analysis** — K-Means clustering for retention strategy
3. **Fake News Detection System** — text classification with Scikit-learn
4. **Crop Yield Prediction** — regression model for climate impact on yield
5. **Customer Review Intelligence** — NLP pipeline (TF-IDF + Logistic Regression), deployed on Streamlit

## Built with

Just plain HTML/CSS, no framework, no build step. One file, keeps it simple and fast to load.

## Running it locally

There's nothing to install. Clone the repo and open `index.html` in your browser.

```bash
git clone https://github.com/sushmita2000g-glitch/Sushmita_Poddar_Portfolio.git
cd Sushmita_Poddar_Portfolio
open index.html
```
